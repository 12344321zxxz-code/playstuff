# Formicarium

A god game. You tend a world the way you'd tend a garden: shape the land, set the sky, seed life,
and watch peoples rise and fall in it. Every system pushes on the others.

## Run it

No build step. Serve the folder and open it:

```
npm run serve     # then open http://localhost:8080
```

`npm test` runs the simulation headless. `npm run build` bundles everything into one HTML file
in `dist/`.

See `DESIGN.md` for what the game is meant to be and where it is going.
